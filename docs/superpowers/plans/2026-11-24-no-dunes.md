# `--no-dunes` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A launch option, `--no-dunes` natively and `?no-dunes` on the web, that makes the terrain shader skip all dune work, with the saving measured.

**Architecture:** `LaunchArgs.no_dunes` becomes a `TerrainOptions { dunes }` resource. `look_for` passes it into `terrain_look`, which writes it into `TerrainLook.wind.w` (unused today, so the uniform's layout doesn't change). `terrain.wesl`'s `desert_at` wraps the whole crest block in a test of that uniform value, so every pixel takes the same branch. The region bench prints `dunes: on|off`. Native and Chrome runs measure the saving.

**Tech Stack:** Rust, Bevy 0.20, WESL/WGSL, wasm32 + WebGPU.

**Spec:** `docs/superpowers/specs/2026-11-24-no-dunes-design.md`

## Global Constraints

- The flag is `--no-dunes` (native) and `?no-dunes` (web query). It is a bare flag: `--no-dunes=VALUE` is not accepted and goes to `LaunchArgs.unknown`, like `--region-bench=VALUE`.
- Dunes are **on** by default: `TerrainOptions::default().dunes == true`.
- When off, the shader runs no dune work: no crest phases, no octave weights for the crests, no small dunes, no warp lookups. `desert.gradient` and `desert.tone` stay 0, so `bound_dune_tilt` gets a zero dune tilt.
- Sand seas keep their place and colour. The sand-sea mask and the stony-plain gravel and mottle still run.
- The switch is a uniform value. No new shader def, no new pipeline key, no new material specialisation: a new pipeline compiled mid-flight costs hundreds of ms on WebGPU.
- The switch lives in `TerrainLook.wind.w`: `1.0` = dunes on, `0.0` = off. The shader tests `look.wind.w > 0.5`.
- The region bench prints a `dunes: on` or `dunes: off` line in every region block and in the summary, right after `system spans:`.
- Repo rules: the worktree is `.superpowers/worktrees/art-pass` on branch `art-pass`; stage explicit paths, never `git add -A`. Commit as `Antonio D'souza <275832+adsouza@users.noreply.github.com>`, ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Never push.
- Build with `PATH="/opt/homebrew/opt/rustup/bin:$PATH"` and `CARGO_TARGET_DIR=/Users/adsouza/Code/time-fly/target`. If `timefly` fails to find an item `timefly_core` plainly has, the shared target dir linked a stale crate: `touch crates/timefly_core/src/lib.rs` and rebuild.
- Windowed runs: a fresh `TIMEFLY_LOG_DIR="$(mktemp -d)"` per run, never a timeout kill.

## Review Focus

1. **`--no-dunes=1` or `?no-dunes=true`.** Someone writes a value. Expected: it isn't taken as the flag. It goes to `unknown`, and the dunes stay on, so a typo never silently changes the look. Test in Task 1.
2. **Flag order.** `?region-bench&no-dunes` and `?no-dunes&region-bench` both turn the dunes off and run the bench. Test in Task 1.
3. **Every region gets the flag.** A snapshot change (`[` / `]`) or a re-entry rebuilds the look through `look_for`, and the flag must survive it. Test in Task 1: `look_for` with `dunes: false` gives `wind.w == 0.0` for two different grids.
4. **A seam at the sand-sea edge.** With dunes off, the erg colour must equal the dunes-on colour where the sand-sea weight falls to 0 (crest tone 0 → factor 1). Checked by the renders in Task 2.
5. **A late pipeline.** The off switch must not add a pipeline variant. Checked in Task 2: no `shader_defs` or `specialize` change in the diff, and the Chrome run's load windows show no new stall.
